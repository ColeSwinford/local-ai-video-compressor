How It Works

  • 100% Private & Client-Side: Video processing runs entirely inside your browser. No files are ever uploaded to an external server.
  • Pass 1 (AI Scene Analysis): An ONNX computer vision model running via WebAssembly analyzes frame complexity to identify visually detailed segments.
  • Pass 2 (Hardware Compression): WebCodecs hardware acceleration dynamically allocates target bitrates to maximize visual quality within your exact size target.
